# Contributing to DeepERC

Thanks for your interest — DeepERC is in early public release and moving quickly.

- Bug reports: open a GitHub issue. Where possible include the netlist snippet involved and the report output.
- Suspected false positives or false negatives are especially valuable — include the board context and the check name from the report.
- Pull requests: for substantial changes, please open an issue to discuss first. Small fixes are welcome directly.
- By contributing, you agree your contributions are licensed under the Apache License 2.0.
